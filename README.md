# 자리온 (JariOn)

Windows에서 실행하는 교실 자리 배치 앱입니다. 기본 Python 표준 라이브러리인 Tkinter만 사용합니다.

## 실행

Python 3.10 이상 설치 후 `seat_allocator.py`를 실행합니다.

```powershell
py seat_allocator.py
```

학생 명단은 UTF-8 또는 CP949 인코딩 `.txt` 파일에서 불러올 수 있습니다. 한 줄에 한 명씩 적으면 됩니다. 쉼표로 구분한 이름도 읽습니다.

## Windows 실행 파일 만들기

Windows에서 프로젝트 폴더를 열고 `build_windows.bat`을 실행합니다. 배포 파일은 `dist\자리온.exe`에 생성됩니다. 빌드 시 인터넷 연결이 필요하며 PyInstaller가 설치됩니다.

## 사용 방법

1. 오른쪽에서 TXT 명단을 불러옵니다.
2. 명단에서 학생을 선택한 뒤 `이름 수정` 또는 `삭제`를 사용할 수 있습니다. 명단 변경은 자동 저장됩니다.
3. `명단 TXT로 저장`을 누르면 수정된 명단을 UTF-8 텍스트 파일로 내보냅니다.
4. `자리 배치하기`를 누르면 이름이 섞이는 애니메이션 뒤 최종 자리가 공개됩니다.
5. `교사 설정`을 처음 열 때 4자 이상의 PIN을 만듭니다. 이후 PIN으로 교사 설정을 열어 행·열 크기와 학생별 고정 자리를 관리합니다.
6. 이름, 자리 크기, 고정 자리, PIN은 사용자 설정 폴더에 저장되어 다음 실행 때 복원됩니다. Windows에서는 `%APPDATA%\JariOn\settings.json`에 저장됩니다.

이름을 수정하면 해당 학생의 현재 자리와 교사 지정 자리도 새 이름으로 이어집니다. 삭제한 학생의 자리와 지정 설정은 해제됩니다. 고정 자리 정보는 학생 화면에서 구분되지 않습니다. 학생들이 함께 보는 화면에서 설정을 열지 않도록 배치 전에 미리 지정해 주세요.
