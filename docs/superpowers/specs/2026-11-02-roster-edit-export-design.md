# 명단 편집 및 TXT 내보내기 설계

## 목적

불러온 학생 명단의 오타를 앱 안에서 수정하거나 학생을 삭제하고, 편집된 현재 명단을 TXT 파일로 저장한다.

## 제안한 접근과 선택

- **선택 행 대화상자 방식 (선택):** 기존 Treeview에서 학생을 선택하고 수정·삭제 버튼을 사용한다. 현재 화면 구조를 유지하면서 명확한 동작을 제공한다.
- 표 안에서 직접 편집: 빠르지만 Treeview의 편집 동작을 별도로 구현해야 한다.
- 별도 명단 관리 창: 공간은 넉넉하지만 작은 기능에 비해 화면과 흐름이 늘어난다.

## 동작

- 명단 표에서 학생 한 명을 선택해 이름을 수정하거나 삭제한다.
- 이름 수정 시 현재 자리 배치와 교사 고정 자리의 학생 참조도 새 이름으로 갱신한다.
- 삭제 시 해당 학생을 명단에서 제거하고 현재 자리 배치 및 고정 자리 참조를 해제한다.
- 추가 및 TXT 불러오기 기능은 유지한다. 불러오기는 기존처럼 현재 명단을 대체한다.
- `명단 TXT로 저장`은 현재 순서와 이름을 UTF-8, 한 줄에 한 명 형식으로 Save As 대화상자를 통해 내보낸다.
- 명단 편집 결과는 즉시 기존 설정 파일에 저장되어 재실행 후에도 유지된다.

## 제약

- 기존 Python/Tkinter 앱과 명단 Treeview를 사용하며 외부 패키지는 추가하지 않는다.
- 빈 이름과 중복 이름은 허용하지 않는다.
